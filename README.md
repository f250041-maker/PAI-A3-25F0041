NumPy, Pandas and Matplotlib on real measurement data (Programming for AI, Assignment 3).

## How to run
1. Install Python with numpy, pandas and matplotlib (Pillow comes with matplotlib).
2. Keep the files in `data/` unchanged and open `Assignment3_Programming_for_AI.ipynb` from this folder.
3. Choose Kernel > Restart and Run All.
4. The notebook saves `outputs/dashboard.png`, `outputs/dashboard.pdf` and `outputs/wave.gif`.
